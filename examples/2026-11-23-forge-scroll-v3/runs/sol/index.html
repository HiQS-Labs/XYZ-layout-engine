Local-first engineering operations

Give every agent run a paper trail.

XYZ Forge coordinates coding agents across your repositories. It carries an issue into a scoped plan, keeps parallel edits apart, and records the checks behind a landed change.

Follow one request ↓

Capture & rate

Turn a request into runnable work.

Suppose support reports that export --format csv produces an empty file when there are no rows. The importer expects a header. The request is to emit the header even when there’s nothing to export.

Capture
Link the GitHub issue to a project capture doc and park the work in the release ledger.
Acceptance
Empty exports contain one header line. Exports with rows retain the existing output.
Priority
Rate priority, severity, appeal, and effort alongside other backlog items.

Plan, preflight & execute

Give the edit a boundary.

The plan allows writes to src/cli/export.ts and test/export.test.ts. The gate covers empty and populated CSV exports.

  1. Schedule around overlapping writes

    The wave planner compares planned write sets. Another issue touching export.ts waits. During execution, the local tick kernel serializes overlapping path claims.

  2. Prove the gate can start

    Preflight checks freshness, looks for work that already landed, and establishes whether the test command can start before the first agent turn.

  3. Run the turn in a worktree

    The driver isolates edits in a temporary worktree by default and copies back only allowlisted files. Turn shims cannot push.

Gate, land & record

Leave evidence someone can check.

A deterministic gate can stop advancement. An independent model reviewer can flag a concern for the operator. The release ledger records what shipped with evidence, and the project docs preserve the state needed for a handoff.

Know the beta limits

Forge is built around one operator. Consult and Relay work from the Forge checkout. Plan on installing PDDA document governance and vendoring Forge into the target repo for Swarm or Marathon.

Flywheel has landed reviewed fixes. End-to-end delivery of two useful tasks without intervention remains unproven. Run on a branch and keep independent, tested backups.
