# Barlow Condensed (starter default font)

Barlow Condensed is the starter default font for new visual work in this repo: use it when neither the user nor the recipe names a font. Existing recipes and diagrams use Inter (`tools/spike/assets/`) and are not changed. See `SYSTEM-INSTRUCTIONS.md` AS-5 and `skills/design-diagram/SKILL.md`.
